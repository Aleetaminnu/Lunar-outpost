# One-minute demo video script

Record the phone screen (portrait) with a voice-over. Keep each shot under 10 seconds.

| Time | Show | Say |
|---|---|---|
| 0:00 | Start screen with the How to play box | "Outpost Zero teaches kids that space survival is about trade-offs." |
| 0:08 | The map, then close it | "You run a lunar base with only a little power each day." |
| 0:15 | Walk to the Supply Depot, press USE, banner and floating numbers | "Every action costs power. Shielding means less science." |
| 0:25 | Solar flare event popup with the NASA source line | "Real NASA space weather data from DONKI makes storms stronger." |
| 0:35 | Day complete message and a locked area opening | "Finish a stage and a new part of the base opens." |
| 0:42 | Call Earth, then show Mars stage | "On Mars, Earth's reply takes up to 48 minutes. You decide alone." |
| 0:52 | Mission report with badges | "Players see how they balanced survival and science." |
| 0:57 | Title and your team name | "Outpost Zero. Built for NASA Space Apps." |
